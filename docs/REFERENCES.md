# External references

YouTube TV Mode was inspired by patterns from **[TizenTube](https://github.com/reisxd/TizenTube)** (GPL-3.0).

The extension does **not** vendor that repository in releases. If you need the reference tree for development:

```bash
git clone https://github.com/reisxd/TizenTube.git references
```

The `references/` path is gitignored so it never bloats this repo or packaged ZIPs.
